# Overview

Condor phase 3 will focus on development of new advanced features that take the app from a simple user-driven analysis tool to add advanced automated analysis based on computer vision & artificial intelligence. This represents a departure from phase 2, which focused on low-technical risk productization. In phase 3, we will explore the possibility of integrating these advanced features, and work through the iterative experimental process to determine what is feasible and get to proof-of-concept demos.

# Scope of new features

We'll spec out new features and assess the approach for one or more technical spike phases:

## Advanced analysis support

- Automatic sync point detection (ball impact)
- Automatically draw key annotations from setup position (can provide example)
- Track human joint position throughout swing
- Trace path of golf ball after impact

Based on our initial review of the level of effort and risk on these new feature requests, we will likely include one or more technical spikes in Phase 3.

## Other new features

- iCloud integration
